# Iris-Portal-2-Mods
Texture, sound, particle mods for portal 2, along with anything else helpful I have, such as .cfg files and potentially some better SAR documentation in the future.

**IMPORTANT NOTE FOR SPEEDRUNNERS:** The only files in this repo that are legal for speedrunning are the ones in `Textures/Speedrun Legal/`. Every other file in here is ILLEGAL for official speedruns unless it SPECIFICALLY SAYS SO IN THE MOD DESCRIPTION!!

# File Layout
Files are organized by mod type (texture, sound, particle, etc.), then by what the mod changes (portal gun, weighted storage cube, old aperture button, etc.). For mods that change only textures, they are also separated by speedrun legal and not speedrun legal (based on [this website](https://rules.portal2.sr/textures/) about allowed texture changes)

Other files such as .cfg files are in a separate folder from mods, but otherwise organized using the same system.

# Downloading and Installing Files
## Mods
These instructions apply to files under the `Textures`, `Sounds`, `Particles`, and `Models` folders. Files under the `Other Mods` folder will contain instructions on how to download them, including any other important information about them.
1. Open the folder for the mod you would like. Download the zip file named after the mod, unzip it, and move it to a place where you can easily access it (desktop, separate file explorer window, whatever works for you).
2. Open your game files
3. Inside `Portal 2` there should be folders titled `portal2_dlc#`. If you have a folder titled `portal2_dlc3`, increment the number on the folder you downloaded from here by 1 (and if you already have `portal2_dlc4` increment it again, and so on) **IMPORTANT NOTE**: you want to create a `portal2_dlc#` folder because those override the base textures, if you replace the `pak01_dir` folder in `portal2`, `portal2_dlc1`, or `portal2_dlc2` it can start breaking things, because you are erasing every single base game files instead of overwriting a couple.
5. Place the folder you downloaded from here into your `Portal 2` folder
6. Launch the game, and you should be set.

## .cfg Files
These instructions apply to files under the `.cfg` folder.
1. Open the folder and download all the .cfg files you would like, and place them where you can easily access them (desktop, separate file explorer window, whatever works for you).
2. Open your game files, then open the folder titled `portal2`, then open the folder titled `cfg`.
3. Drop all the .cfg files into that folder.

To run .cfg files, all you need to do is open the console and type `exec ` followed by the name of the file you want to run.

# Basic Tutorials
## Opening Game Files
1. Open Steam and find Portal 2 in your games library
2. Click the settings icon on the right side and go to Manage > Browse Local Files
3. It should open a folder titled `Portal 2`

If you want to download a lot of mods, or you find yourself using this folder often, I would recommend pinning it to your quick access in file explorer.

## Opening Developer Console
1. Launch Portal 2 and open the settings menu
2. In `Keyboard/Mouse` at the bottom, there should be a setting at the bottom called `Allow Developer Console`, make sure it is enabled.
3. By default, the console is bound to the "`" key, which is the one on the top left of your keyboard, right above the "tab" key.

# Iris-Portal-2-Mods
Texture, sound, particle mods for portal 2, along with anything else helpful I have

# File Layout
Files are organized by mod type (texture, sound, particle, etc.), then by what the mod changes (portal gun, weighted storage cube, old aperture button, etc.). For mods that change only textures, they are also separated by speedrun legal and not speedrun legal (based on [this website](https://rules.portal2.sr/textures/) about allowed texture changes)

Other files such as .cfg files are in a separate folder from mods, but otherwise organized using the same system.
